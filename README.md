`site.css` and `site.js` are shared by every page. Images sit next to the pages, and there are no folders, so uploading through GitHub's web page can't break the layout.

## Editing

The pages are generated by `src/build.py` (shared header, nav and footer live in `src/common.py`). Edit the text there and run `python3 src/build.py`, or edit the HTML files directly for small fixes.

The Helix simulator is a concept demonstration from an MBA capstone. Capabilities are modeled on technologies evaluated from NASA's public technology-transfer catalog; no licenses were obtained. Not affiliated with or endorsed by NASA or Elroy Air. Finance pages are student research for educational purposes, not investment advice.
